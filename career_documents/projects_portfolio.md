# PROJECT 1

## Career Operating System

### Project Category

Software Development • Career Automation

### Project Status

In Progress

### Overview

Designed and developed a Python-powered Career Operating System that automatically generates a professional portfolio website, ATS résumé, curriculum vitae, cover letters and supporting career documents from a single source of truth using structured YAML data and reusable templates.

### Purpose

To eliminate repetitive document editing, maintain consistency across professional documents and demonstrate the practical application of software engineering principles to career management.

### Key Features

- Automated website generation
- Automated résumé generation
- Automated CV generation
- Modular HTML templates
- YAML-driven content management
- Reusable Python rendering system
- Git version control
- Responsive portfolio website
