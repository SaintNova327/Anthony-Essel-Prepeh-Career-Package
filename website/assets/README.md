# Website Assets

This directory stores all static assets used by the portfolio website.

## Structure

```text
assets/
│
├── images/
├── icons/
├── documents/
├── fonts/
└── downloads/
```

## Folder Descriptions

### images/
Profile photographs, project screenshots, certificate images, logos, and background images.

### icons/
SVG, PNG, and favicon files used by the website.

### documents/
Supporting documents referenced by the website.

### fonts/
Custom web fonts used by the website.

### downloads/
Files available for visitors to download, such as:

- Resume PDF
- ATS Resume PDF
- Executive Resume PDF
- Academic CV PDF
- Cover Letters

These files will eventually be updated automatically by the build system.
